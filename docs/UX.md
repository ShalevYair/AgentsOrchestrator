## 4. כרטיס התוכנית

מופיע בזרם הצ'אט כשהתוכנית מוכנה. מכווץ = שורה אחת. מורחב:

**עריכה** (כשהאישור המוקדם דלוק): שינוי מספר סוכנים, מקביליות, דרגת קריאה, הסרת שלבים אופציונליים.
כל שינוי מעדכן את הצפי מיידית. אין חריגה מהתקציב — ה-UI חוסם.

**כשהתוכנית מתוקנת תוך כדי ריצה** (`plan.amended`) הכרטיס מתעדכן במקום, עם באנר שינוי ודיף לחיץ.
המשתמש רואה שהמערכת שינתה כיוון, מתי ולמה. **זה הפיצ'ר שבונה אמון.**

## 5. לוח התזמור

**רמה 1 — שלבים:** מצב (⏳/✅/⚠️/⏭️), סוכנים פעילים/סה"כ, פס התקדמות, טוקנים בפועל מול צפי.

**רמה 2 — סוכנים:** שורה לכל Task: מזהה הפלח, מצב, טוקני קלט/פלט, זמן.

**רמה 3 — קופסה שקופה:** לחיצה על סוכן פותחת מגירה עם:
- **הקשר** — מה בדיוק הוא קיבל, מפורק לרכיבים (Contract / פלח / ראיות / ממצאים) עם ספירת טוקנים לכל אחד
- **פלט** — מעטפות NDJSON מפורסרות, זורמות בזמן אמת
- **שימוש** — טוקנים, זמן, `finishReason`, הפרות סכמה, פגיעות מטמון
- **פעולות** — העתקת הפרומפט · הרצה חוזרת · ייצוא JSON

**זה הכלי לניפוי באגים במערכת ולשיפורה.** כשתשובה יוצאת גרועה, התשובה ל"למה" נמצאת כאן.

## 6. תשובות ותוצרים

**Markdown מלא:** GFM (טבלאות, רשימות משימות, קו חוצה) · הדגשת תחביר עם Shiki + כפתור העתקה + שם קובץ ·
Mermaid מרונדר · KaTeX למתמטיקה · קישורים לתוצרים · **ציטוט מקורות** — טענה עם ראיה מקבלת עוגן לחיץ
שפותח את הקטע המקורי.

**כרטיס ארטיפקט:** שם + סוג + גודל · תצוגה מקדימה (קוד / Markdown / תמונה / טבלה ל-CSV) ·
**דיף** מול המקור אם זה עדכון · הורדה · הורדת הכל כ-ZIP · "כתוב לתיקייה" (רק בהרשאה).

**כתיבה לתיקייה** היא תמיד דו-שלבית: מסך diff מרוכז → אישור מפורש → כתיבה עם גיבוי אוטומטי
של הקבצים שהוחלפו. אף פעם לא שקטה.

## 8. הגדרות

**מפתח API** — הכנסה חד-פעמית עם אימות חי מול `models.list`. מוצג ממוסך (`AIza••••3f2a`).
כפתורי החלפה ומחיקה. **הכי חשוב:** אינדיקציה מפורשת היכן הוא נשמר —
*"נשמר ב-Keychain של מערכת ההפעלה"* או *"נשמר בקובץ מוצפן ב-`~/.aorc/`"*.

**מודלים** — טבלת השכבות (`cheap` / `worker` / `synth`), בחירת מודל לכל אחת, מחירים, ואימות זמינות.

**נוסף:** ברירות מחדל לתקציב · הרשאות (סקריפטים, כתיבה) · שפה (עברית/אנגלית) · ערכת נושא ·
`.aoignore` גלובלי · ייצוא/ניקוי היסטוריית ריצות.

## 9. עברית, RTL ונגישות

| נושא | דרישה |
|---|---|
| כיוון | `dir="rtl"` על הגוף. **קוד, מסלולים, מזהים ומספרים תמיד LTR** — עטיפה ב-`<bdi>` / `dir="ltr"`. |
| Markdown מעורב | פסקה עברית עם מונח אנגלי חייבת להיראות נכון. **מקרה בדיקה חובה.** |
| טיפוגרפיה | פונט עברי קריא (Assistant / Heebo) + מונו לקוד. אין הסתמכות על ברירת מחדל של הדפדפן. |
| i18n | כל מחרוזת דרך `t()` מהיום הראשון. עברית ברירת מחדל, אנגלית מלאה. |
| מקלדת | `Ctrl+K` פקודות · `Ctrl+Enter` שליחה · `Esc` עצירה · ניווט מלא בלוח התזמור |
| קורא מסך | תוויות ARIA · `aria-live` להתקדמות · **מצב לא מסומן רק בצבע** אף פעם |
| ניגודיות | WCAG AA בשתי ערכות הנושא |
| תנועה | כיבוד `prefers-reduced-motion` |
