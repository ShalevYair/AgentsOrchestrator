## דרישות מקדימות

| דרישה | חובה? | למה |
|---|---|---|
| **Node.js 22 ומעלה** | כן | האפליקציה רצה על Node. הורדה: [nodejs.org](https://nodejs.org) |
| **מפתח API של Gemini** | לא בהתחלה | בלי מפתח האפליקציה עדיין עולה ועובדת עם תשובות-דמה, כדי שתוכלו לראות את הממשק לפני שאתם נרשמים לשירות |
| **Python 3.11 ומעלה** | לא | רק לכלים מקומיים (הרצת סקריפט ניתוח-נתונים וכו'). בלעדיו האפליקציה עובדת נורמלי, רק הכלים האלה כבויים — עם הסבר ברור בהגדרות |
| **Docker Desktop** | לא | משפר את רמת הבידוד של סקריפטים מקומיים. בלעדיו יש בידוד חלקי (ברירת המחדל של מערכת ההפעלה) — גם זה מוצג בבירור בהגדרות |

**אין** דרישה לכלי בנייה של Visual Studio, ל-`node-gyp`, או להתקנה ידנית של תלויות נוספות — לא ב-Windows ולא בשום פלטפורמה אחרת.

## התקנה והרצה

```bash
npx agents-orchestrator
```

פקודה אחת: היא מורידה, מריצה שרת מקומי, ופותחת דפדפן אוטומטית בכתובת המקומית שלו (בדרך כלל
`http://127.0.0.1:8787/`). אם הפורט הזה תפוס — האפליקציה בוחרת פורט פנוי אחר לבד ומדפיסה את הכתובת
המדויקת לטרמינל.

אם הדפדפן לא נפתח לבד (קורה בסביבות מסוימות, למשל שרת ללא ממשק גרפי) — פשוט העתיקו את הכתובת
שהודפסה בטרמינל לדפדפן שלכם.

**עצירה:** `Ctrl+C` בטרמינל שבו הפקודה רצה.

**דגלים אופציונליים:**

```bash
npx agents-orchestrator --port=3000       # פורט קבוע במקום 8787
npx agents-orchestrator --host=0.0.0.0    # להאזין על כל הכתובות, לא רק localhost
npx agents-orchestrator --no-open         # לא לפתוח דפדפן אוטומטית
```

> **לפני שחרור v1.0.0 לרשם ה-npm** (ראו [`TASKS.md` P12-T8](TASKS.md#p12)), הריצו במקום זאת מתוך שיבוט
> המאגר: `pnpm install && pnpm build && node apps/cli/dist/cli.js`. ההתנהגות זהה לחלוטין.

### היכן נשמרים הנתונים

כל מה שהאפליקציה שומרת — היסטוריית שיחות, קבצים שהועלו, מטמונים — יושב תחת `~/.agents-orchestrator`
(באותה תיקייה בשלוש הפלטפורמות). מפתח ה-API נשמר בנפרד, ב-Keychain המאובטח של מערכת ההפעלה (או בקובץ
מוצפן אם אינו זמין) — **לעולם לא** בתוך `~/.agents-orchestrator` ולא בטקסט גלוי.

## הרצה ראשונה

1. **מפתח API (אופציונלי בהתחלה).** בפעם הראשונה, אם אין עדיין מפתח שמור, תוצג הודעת "ברוכים הבאים"
   עם קישור להשגת מפתח חינמי מ-Google AI Studio, וכפתור "המשך בלי מפתח (מצב הדגמה)" שמאפשר לכם
   לחקור את הממשק בלי להירשם קודם. מפתח אמיתי נדרש רק כדי לקבל תשובות אמיתיות מ-Gemini במקום דמה.
2. **הכניסו את המפתח בהגדרות** (סמל גלגל השיניים) — הוא מאומת מול Google **מיד** בהקלדה, לא רק
   נשמר; מפתח שגוי מקבל הודעת שגיאה ברורה, לא קריסה.
3. **כתבו הודעה ראשונה** בתיבת הצ'אט — לדוגמה "סכם לי את הקובץ הזה" עם קובץ מצורף, או שאלה פשוטה
   בלי קובץ בכלל. התשובה זורמת תו-אחר-תו, ומונה הטוקנים בכותרת מתעדכן בזמן אמת.
4. **צרפו קובץ או תיקייה שלמה** דרך כפתור ההיצמדות — קבצי קוד, PDF, Word, Excel, תמונות וארכיוני
   ZIP נתמכים. קבצים גדולים מעובדים מקומית (חילוץ טקסט, מיפוי) **לפני** שנשלח טוקן אחד לרשת.
5. **לכל שלב בתגובה יש כרטיס תוכנית ולוח תזמור** שמראה אילו סוכנים רצים, במקביל או ברצף, ובאיזה
   עלות — לא רק "התשובה מתעבדת" בלי הסבר.

## כפתור המטרה — מדריך תקציב

ליד כפתור השליחה יושב כפתור **מטרה** שקובע כמה טוקנים (יחידות העיבוד של Gemini) מותר לשרוף על
ההודעה הזאת:

| רמה | תקציב | מתאים ל־ |
|---|---|---|
| ✏️ טיוטה | 500K טוקנים | שאלה ממוקדת, קובץ בודד, סקירה מהירה |
| ⚖️ סטנדרט (ברירת מחדל) | 2.5M טוקנים | מסמך, ניתוח, פיצ'ר בפרויקט |
| 🔬 עומק | 5M טוקנים | פרויקט שלם, מחקר רחב, ריפקטור חוצה-קבצים |
| ⚙️ מותאם | כל ערך שתבחרו | שליטה ידנית מלאה |

תחת "מתקדם" בכפתור המטרה יש שתי הגדרות נוספות שכדאי להכיר:

- **מדיניות חריגה** — מה קורה אם המשימה בפועל דורשת יותר מהתקציב שקבעתם:
  - **הידרדרות מבוקרת** (ברירת המחדל) — האפליקציה ממשיכה עם פחות הקשר, פחות סוכנים במקביל, או מודל
    זול יותר, כדי בכל זאת להחזיר תוצאה בתוך התקציב. תמיד מוחזר תוצר — אף פעם לא נתקעים.
  - **לשאול** — האפליקציה עוצרת ושואלת אתכם לפני שהיא חורגת.
  - **לעצור** — האפליקציה עוצרת מיד ומחזירה מה שהושלם עד כה.
- **רמת מאמץ** — כמה "לחשוב" המודל לפני שהוא עונה (נמוך/בינוני/גבוה). גבוה יותר = תשובות איכותיות
  יותר במשימות מורכבות, אבל יקר יותר.

ה-**$** שמוצג ליד כל רמה מחושב **מטבלת המחירים האמיתית** של המודל הנבחר, לא מספר קבוע — הוא
מתעדכן לבד אם המחיר משתנה.

## פתרון תקלות

| מה קורה | מה זה אומר | מה לעשות |
|---|---|---|
| "Python not found" / "Python לא נמצא" בהגדרות | אין Python 3.11+ בנתיב המערכת | האפליקציה **עדיין עובדת** — רק הכלים שמריצים סקריפט Python מושבתים. אם תרצו אותם: ההודעה עצמה כוללת קישור התקנה מדויק **לפלטפורמה שלכם** (ב-Windows: python.org, לא `apt`) |
| "Docker unavailable" / בידוד חלקי | אין Docker Desktop מותקן/רץ | האפליקציה עדיין עובדת; סקריפטים מקומיים רצים בבידוד חלקי בלבד (התלוי בפלטפורמה — הפירוט מוצג בהגדרות). להגנה מלאה: התקינו Docker Desktop |
| הפורט שהודפס שונה מ-8787 | פורט 8787 היה תפוס (למשל אפליקציה אחרת) | אין צורך לעשות כלום — האפליקציה בחרה פורט פנוי לבד ופתחה את הדפדפן בכתובת הנכונה |
| הדפדפן לא נפתח לבד | קורה בשרתים בלי ממשק גרפי, או אם `--no-open` הועבר | העתיקו את הכתובת שהודפסה בטרמינל (`http://127.0.0.1:<port>/`) לדפדפן ידנית |
| "המפתח שהוזן אינו תקין" | המפתח שגוי, פג תוקף, או בלי הרשאה | בדקו את המפתח ב-Google AI Studio ונסו שוב — ההודעה תמיד ברורה, אף פעם לא stack trace גולמי |
| רוצים להתחיל מאפס | למחוק את כל הנתונים השמורים | מחקו את התיקייה `~/.agents-orchestrator` (השרת חייב להיות סגור קודם) |
