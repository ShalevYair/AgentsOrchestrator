# טלמטריה

> P12-T7. **מצטרפים מרצון בלבד. כבויה כברירת מחדל. מקומית בלבד — שום דבר לא נשלח לשום מקום.**

## מה זה בכלל

לוג JSONL מקומי (`~/.agents-orchestrator/telemetry/events.jsonl`) שמתעד **שלושה** סוגי אירועים בלבד,
כל אחד מוגדר בסכמת Zod (`packages/platform/src/telemetry/events.ts`) שאוכפת `z.strictObject` — שדה
נוסף שלא הוגדר מראש **נכשל בוולידציה**, לא רק "לא אמור לקרות" מוסכם:

| אירוע | מתי | שדות |
|---|---|---|
| `app_started` | בכל עליית שרת | גרסת אפליקציה, גרסת Node (מספר major בלבד), מערכת הפעלה, `gemini`/`mock` (האם הוגדר מפתח API אמיתי) |
| `run_completed` | בסיום מוצלח של שיחה | משך זמן במילישניות בלבד |
| `run_failed` | בכישלון שיחה | משך זמן + **קוד שגיאה יציב** (למשל `BUDGET_EXCEEDED`) |

**לעולם לא נאסף:** תוכן הודעות, פרומפטים, תשובות, שמות קבצים, נתיבים, מפתח ה-API, או טקסט השגיאה
הגולמי (רק הקוד היציב שלה). זו לא הבטחה בעלמא — הסכמה עצמה פיזית לא מאפשרת שדה כזה.

## ברירת מחדל: כבויה

בהתקנה טרייה `telemetryEnabled` הוא `false`. שום תיקיית `telemetry/` לא נוצרת בכלל, ואף קריאת
`record()` לא כותבת דבר — לא "לוג ריק", אלא קוד שלא נוגע בדיסק בכלל
(`packages/platform/src/telemetry/recorder.ts`).

## איך מפעילים

**קובץ קונפיג** (`~/.agents-orchestrator/config.json`, ראו [`config.example.jsonc`](../config.example.jsonc)):

```jsonc
{ "telemetryEnabled": true }
```

**משתנה סביבה** (עוקף את קובץ הקונפיג):

```bash
AO_TELEMETRY_ENABLED=true npx agents-orchestrator
```

⚠️ רק המחרוזת המדויקת `"true"` מפעילה — כל ערך אחר (כולל `"1"`, `"yes"`) נשאר כבוי, כדי שלא יהיה
אפשר להפעיל בטעות עם ערך לא-מכוון. אין עדיין מתג בממשק שמשנה את הערך הזה תוך כדי ריצה (זו הגדרה
שנקבעת בעליית השרת, כמו `dataDir`/`logLevel`) — הגדרות מציגות **מה המצב עכשיו**, לא מאפשרות
לשנות אותו בלי לערוך את הקונפיג ולהפעיל מחדש.

## איך מכבים / מוחקים

כיבוי: הסירו את `telemetryEnabled`/הגדירו `false` בקונפיג, או `AO_TELEMETRY_ENABLED=false`.
מחיקת מה שכבר נאסף: מחקו את `~/.agents-orchestrator/telemetry/` — קובץ טקסט רגיל, אין מנגנון
סנכרון או גיבוי מרוחק שצריך "לבטל" קודם.

## למה בכלל

הצורך היחיד: לדעת אם האפליקציה בשימוש בכלל ואם שיחות מסתיימות בהצלחה, בלי לבנות שרת איסוף חיצוני
שהפרויקט הזה לא מחזיק (ADR-001, A3 ב-[`DECISIONS.md`](DECISIONS.md)) ובלי לסתור את עיקרון "קופסה
שקופה" (README, עיקרון #5): גם הטלמטריה עצמה גלויה, מתועדת, וניתנת למחיקה בקובץ טקסט רגיל.
